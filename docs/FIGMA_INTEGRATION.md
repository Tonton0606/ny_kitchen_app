## Design System Tokens
The UI/UX for N.Y. Kitchen is driven by the tokens established in the `ui-ux-pro-max` and `design-system` skills. This Figma workspace must align with those tokens.

- **Primary Colors**: Yellow (#FFC107), Red (#D32F2F)
- **Neutral Colors**: White, Black, Greys
- **Typography**: Material 3 defaults (Roboto)
- **Spacing**: 4px baseline grid (4, 8, 16, 24, 32, 48, 64)

## Handoff Process
1. Designers update Figma and notify the engineering team.
2. Engineers cross-reference updates against `docs/UI_GUIDELINES.md` and `docs/DESIGN_SYSTEM.md`.
3. Extract necessary assets (e.g., SVG icons) and place them in the appropriate `assets/` directory.
4. If a design violates `PROJECT_BLUEPRINT.md` constraints (e.g., adding inventory management), it must be rejected.
