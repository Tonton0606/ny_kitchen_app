# N.Y Kitchen — Client Demo Plan

---

## Purpose
Script for demonstrating N.Y Kitchen to the client (food stall owner).

---

## Demo Sequence

1. Login as Cashier
2. Process a sample order (add items, checkout, generate receipt)
3. Show receipt preview and printing
4. Logout and login as Admin
5. Show Admin Dashboard (revenue, analytics, security summary)
6. Show Transaction History with filters
7. Show Menu Management (add/edit/archive item)
8. Show User Management (create/deactivate user)
9. Show Activity Logs (read-only audit trail)
10. Show Reports (daily sales, best sellers)
11. Show Backup and Restore

## Demo Data
- Use mock food items and transactions for demo.
- Do not use real business data in demo environment.

## Offline Demo
- Demonstrate that the application works when WiFi is disabled.
