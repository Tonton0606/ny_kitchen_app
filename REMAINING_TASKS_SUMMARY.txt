  1. Administrator:
     - Access to Back Office, Financial Sales Reports, Menu Management, 
       User Account Provisioning & Unlocking, System Backups, Audit Logs.

       Order Voiding (Preparing), Order Refunding (Served), Personal Activity Logs.

4. HOW TO TEST & DEMO SECURITY FEATURES DURING DEFENSE
--------------------------------------------------------------------------------

A. ACCOUNT LOCKOUT (BRUTE FORCE DEFENSE)
   - Step: Enter incorrect password 5 times at login.
   - Result: 6th attempt alerts "Account locked due to multiple failed login attempts".
   - Reset: Log in as Admin -> Account Management -> Click amber Unlock button.

B. FORCED PASSWORD CHANGE (CREDENTIAL ROTATION)
   - Step: Admin clicks "Reset Password" on any user -> enters temp password.
   - Result: User logs in -> Route guard blocks POS access -> Modal forces new password.

C. REPOSITORY ROLE GUARD (RBAC NON-BYPASSABILITY)
   - Step: Attempt to call Admin functions while logged in as Cashier.
   - Result: Guard throws `SecurityException: FORBIDDEN_ROLE`. UI cannot bypass backend.

D. PASSWORD HASHING UPGRADE
   - Legacy hashes (10,000 iterations) automatically upgrade to 600,000 iterations 
     PBKDF2-HMAC-SHA256 upon successful login without disrupting user workflow.
